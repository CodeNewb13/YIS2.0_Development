# YIS Project

Monorepo sederhana dengan frontend Next.js dan backend TypeScript.

## Menjalankan project

```bash
npm install
npm run dev
```

- Frontend: http://localhost:3000
- Backend health check: http://localhost:4000/api/health

## Struktur

- `fe/`: Next.js App Router + TypeScript + Tailwind CSS
- `be/`: Express + TypeScript
